# @lsw-abpvue/template-lib

The Vue UI of the Sample ABP module, generated by `abpv create-lib`.

```bash
pnpm install
pnpm build
```

## What is in here

| | |
| --- | --- |
| `src/` | The pages, the extension points and the routes. The package's main entry point |
| `config/src/` | The menu entries and the permission names. Imported at startup, so it holds no component |
| `proxy/src/` | Where `abpv proxy add --target proxy/src` writes the generated services |

Three entry points, because an application needs the menu before it needs the pages: an
application that never opens this module still pays for `config`, and it is a few hundred
bytes.

## Wiring it into an application

```ts
// main.ts -- the menu, at startup
provideSampleConfig();

// routes.ts -- the pages, lazily
lazyRoutes('/sample', () => import('@lsw-abpvue/template-lib').then(m => m.createSampleRoutes()));
```

## Making it extensible

The page renders through `AbpExtensibleTable` and `AbpExtensibleForm`, so a host adds a
column without touching this package:

```ts
createSampleRoutes({
  entityPropContributors: {
    [SampleComponents.Sample]: [
      props => props.addByIndex(EntityProp.create({ type: PropType.String, name: 'code', displayName: 'Code' }), 1),
    ],
  },
});
```

The five extension points -- entity props, create and edit form props, entity actions and
toolbar actions -- are assembled by `sampleExtensionsResolver` before the page renders, in
the order that decides priority: this package's defaults, then the backend's object
extensions, then the host's contributors.

## Next

1. Point `SamplePage` at your own endpoints, or generate a proxy and inject the service it
   writes.
2. Rename `Sample` to whatever your module is called, in the component key, the permission
   names and the route names. The component key is public API: a host replaces the page by
   it, so pick it once.
3. Give the backend's localization resource the texts the page asks for: `Sample::Name`,
   `Sample::Menu:Sample` and `Sample::DeletionConfirmationMessage`.
