# Tutorials

Choose a tutorial according to what you own:

- [Build a business page](./crud): application-specific proxies, explicit columns, forms and CRUD methods.
- [Extend the users page](./extend-users): add a column and an action to an existing module through contributors.
- [Run the backend examples](./backend-examples): supply the catalogue, printing settings and report endpoints used in the guides.
- [Create a reusable module](./module): publish routes, configuration and proxies with extension points for host applications.

Start with a running ABP backend and a frontend that can sign in. [Quick Start](/guide/new-solution) covers a new solution; [existing solutions](/guide/existing-solution) covers adding Vue to your backend. CLI examples use the project's installed CLI so generation matches its package version.
