# 应用测试

在生成的前端中测试自己的业务行为。使用与应用一致的提供者，并配置独立的测试后端与数据。

## 选择测试层次

| 层次 | 适合检查的内容 |
| --- | --- |
| 类型检查 | DTO 变化、组件属性、类型化服务调用 |
| 组件测试 | 字段错误、忙碌状态、权限控制、模态框取消 |
| 后端集成 | 查询参数、租户头、验证与并发错误 |
| 浏览器测试 | 登录跳转、回调、CRUD、My account 与退出 |

部署前运行生成项目的类型检查和生产构建。具体脚本以当前模板版本的 `package.json` 为准。

## 认证与隔离

浏览器测试使用专门的测试账户，后端需要允许前端来源。登录和退出应遵循当前认证流程，测试不应依赖其他标签页已有的会话。

使用可识别的记录名称，结束后清理自己创建的数据。覆盖有权限和无权限用户；前端显隐检查需要与后端授权测试配合。

## 文档示例

文档中的完整示例保存在 `docs/examples`，通过 `vue-tsc` 检查。组件参考页从公共契约与实现默认值提取。其他页面中的短片段用于展示单个 API，使用时应补充应用自己的数据和处理函数。
