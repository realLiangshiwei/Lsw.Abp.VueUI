# abpv doctor

```bash
abpv doctor
abpv doctor --token "$ACCESS_TOKEN"
abpv doctor --offline
```

| 选项 | 用途 |
| --- | --- |
| `--token <token>` | 同时比较权限名称 |
| `--offline` | 只检查不需要后端的内容 |
| `--solution <dir>` | 检查位置 |

共十项检查，各失败项输出修复命令，具体含义见[问题排查](../guide/troubleshooting)。

## 两项诊断的机制

**代理新鲜度**不依赖哈希。根据 `generate-proxy.json` 记录的选项在内存中重新生成，逐文件与磁盘比较。因此早于此检查创建的项目也能检查，无须事先记录哈希。

**对象扩展覆盖**比较后端声明数量与映射规则识别数量，并逐属性指出差异。缺失规则表现得像应用配置错误，所以需要具体诊断。被指出的未识别属性属于项目映射缺口。

没有 token 时跳过权限名称比较并说明原因。匿名 `grantedPolicies` 为空，不能把与空集合比较当作一致。

已测试 ABP 次版本为 10.5、10.6。其他版本产生警告，不阻止应用启动。

方案元数据允许注释、结尾逗号，包括 ABP 模板保留的格式。无效元数据或缺少版本会产生警告，其他诊断仍可继续。
