# 教程

按代码归属选择教程：

- [开发业务页面](./crud)：应用自己的代理、显式列、表单和 CRUD 方法。
- [扩展用户页面](./extend-users)：通过贡献者给已有模块添加列和操作。
- [运行后端示例](./backend-examples)：提供指南使用的目录、打印设置和报表端点。
- [创建可复用模块](./module)：提供路由、配置和代理，并为宿主应用保留扩展点。

开始前需要运行中的 ABP 后端，以及能够登录的前端。[快速开始](/zh/guide/new-solution)介绍新建方案，[已有方案接入](/zh/guide/existing-solution)介绍给后端增加 Vue。命令示例使用项目安装的 CLI，使生成结果与依赖版本一致。
