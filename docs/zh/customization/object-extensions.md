# 对象扩展

ABP 在应用配置中发送模块对象扩展元数据，可扩展模块页面将受支持的属性映射为表格列和新增、编辑控件。

## 映射内容

映射读取属性类型、本地化、验证注解、枚举选项、UI 显隐、顺序、权限与功能条件、查找配置和只读行为。运行时值位于 `extraProperties` 中。

后端元数据需要指定模块使用的实体，例如 `Identity.User`、`TenantManagement.Tenant`。在 ABP 后端配置扩展后刷新应用配置。宿主贡献者在模块默认项和对象扩展映射之后执行，可以重新排序或移除生成字段。

## 业务页面

普通生成业务页面显式定义列与表单控件。扩展属性需要自行添加控件和绑定，更新请求保留 `extraProperties`；这些页面不会自动应用模块映射。

## 排查缺失字段

检查 `/api/abp/application-configuration` 是否包含元数据、当前权限与功能条件是否允许显示、模块实体名称是否匹配。`abpv doctor` 会比较后端元数据与受支持的映射。

查找属性需要可用的查找端点和显示值，未知元数据不会自动生成任意控件。[页面扩展](/zh/concepts/extensions)介绍自定义控件和取值函数。
