# API 参考

参考页覆盖工作区包的公共导出，包括各包实际提供的 config、proxy、router、object-extensions 和 testing 入口。

## 先了解行为

[服务与组合式函数速查](./services)将常见任务对应到服务，[组件](/zh/components/)列出属性、事件、插槽与默认值。各包页面列出导出的值与类型，并链接到源码声明。

## 版本范围

站点随 `main` 更新，当前已发布 alpha 版本见[版本与兼容性](/zh/release/compatibility)。复制 API 前请比较已安装版本与发布记录，源码导出可能新于已安装包。

使用文档中的公共包入口。内部文件路径属于实现细节，应用生成的业务 DTO 由自己的后端决定，不属于共享参考。

## 导入

值导出存在于运行时，纯类型导出需要 `import type` 或行内 `type` 修饰符。应用预设可以自动导入常用运行时 API，显式导入仍然有效，可复用组件库建议使用显式导入。
