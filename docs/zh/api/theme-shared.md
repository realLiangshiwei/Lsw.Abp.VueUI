# @lsw-abpvue/theme-shared

按导入入口列出公开导出。值导出存在于运行时；类型导出使用 `import type`。源码链接指向对应声明。

本参考跟随 **main**。npm 已发布通道是 **alpha**；使用尚未发布的变更前请查看[版本与兼容性](/zh/release/compatibility)。

## 导入

```ts
import { AbpButton } from '@lsw-abpvue/theme-shared';
```
