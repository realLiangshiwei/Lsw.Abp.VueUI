# 版本与兼容性

站点从 `main` 构建，描述该分支的当前源码，不是所有历史版本的固定手册。

## 已发布包

稳定版使用 `latest` 标签，安装命令不指定版本或标签时默认选择它。应用中的公共 ABP Vue 包应使用同一个发布版本。预发布使用 `alpha`、`beta`、`rc` 标签，需要显式选择。

```bash
npm view @lsw-abpvue/cli dist-tags
npm list @lsw-abpvue/core @lsw-abpvue/cli
```

标签可能更新，第一条命令检查可用标签，第二条检查实际安装版本。

已发布版本及其变化见[发布记录](./releases)。

## 兼容范围

CLI 将 ABP 10.5、10.6 识别为已测试的小版本。其他版本会提示诊断警告，需要针对对应后端验证。端点可用性还取决于后端安装的 ABP 模块与版本类型。

CLI 要求 Node 20 或以上，应用使用 Vue 3 与 Vue Router 4，后端 .NET SDK 和 ABP CLI 应匹配目标解决方案。

## 能力范围

| 能力 | 当前范围 |
| --- | --- |
| 内置开源模块 | 账户、身份、权限、租户、功能、设置；后端模块与权限必须可用 |
| SSR | 平台抽象支持服务端安全访问，尚无完整生成模板 |
| PWA | 尚无预置服务工作线程与离线模板 |
| 模态框全局确认开关／fullscreen | 尚未实现，见[模态表单](/zh/utilities/modals) |
| 动效 | 进一步体验在 Backlog，显隐事件不代表动画结束 |
