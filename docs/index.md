## About this documentation

This is an unofficial community project, MIT licensed and not affiliated with Volosoft. The site follows `main`; published alpha packages can lag behind it. Check [versions and compatibility](/release/compatibility) for your installed release.

The backend already provides the framework endpoints. Frontend URLs, CORS and OpenIddict client configuration still need to agree; the CLI helps configure them. Start with [a new solution](/guide/new-solution) or [an existing ABP solution](/guide/existing-solution).
